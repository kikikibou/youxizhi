# 弃稿

这里记录 `/new-world` 提过、但站主没有选的视觉方向。按站主说的否决理由分两类：

- **不喜欢**：站主不喜欢这个方向本身，永久排除，给任何子站都不再提。
- **不适合某个子站**：方向本身可以，只是不适合那个子站。只在给**同一个子站**提方向时排除；给别的子站可以再提，但要注明「曾为某子站提过」。

怎么算「同一个方向」：同一个具体来源算；同一个领域而且长得像，也算。

只追加，不删除。只有站主自己要求时，才改某一条的类型。

## 每条的格式

```
### <方向名>（<日期>，为 <子站代号> 提出）
- 取材来源：<领域> · <具体来源>
- 借来的特征：<三条，用分号隔开>
- 版式骨架：<信息排法>；主视觉约 <N>%；<网格>
- 样张：设计世界/样张/<代号>/<序号>-<短名>.html（截图在同目录的 shots/ 下；这个目录不进仓库，只在这台电脑上）
- 理由：<站主的原话或概括；只选了类型、没多说的就写「未细说」>
```
