# new-world：给新子站选一个视觉世界

站主要开一个新子站（小镇里的一扇新门）时用。目标是给它一个和全站其他世界都不像的世界。

本技能只做到「选定世界、写好 DESIGN.md」为止，**不写正式代码**。之后怎么接着做，见 `设计世界/开新子站.md`。

## 0. 弄清楚这是个什么子站

从参数和对话里拿到下面这些：

- **名字和代号**：代号是小写拼音缩写，比如 `sgjm`、`dgxg`。
- **它是什么**：内容是什么、怎么玩、访客来做什么。样张要用真内容，不能用 lorem ipsum。
- **主要设备**：手机、电脑，还是两边都要。
- **源码放哪**：默认是 `src/<代号>/`，入口 `<代号>/index.html`，和《解码》一样。如果像《大国小国》那样是独立应用，就按它的实际目录。DESIGN.md 最后要放在源码目录里，impeccable 才能按文件路径找到它。
- **参考图或关键词**：可选。

能从仓库或对话里推出来的，不要问。缺的东西用 AskUserQuestion 问一次，最多 3 个问题。

## 1. 读现有世界，只为知道「不能像什么」

1. 用 Glob 找出所有 `**/DESIGN.md`（排除 `node_modules`），全部读完。
2. 读 `设计世界/弃稿.md`。
3. 读 `PRODUCT.md`，但只看产品约束，不看审美。
4. 在回复里列一张**禁区清单**，让站主扫一眼：
   - **已用的取材领域。** 先看每份 DESIGN.md 里的「取材来源」那一行；没有这一行的，从 Overview 推断。根 DESIGN.md 里提到的外部姊妹站也算，比如「攻错」的黑金装饰朋克。
   - **各世界的招牌。** 主色、标志字体、招牌组件。
   - **弃稿里的所有方向。**

这些世界**只用来排除，不用来继承**。现有世界的配色、字体、组件、纹理、动效都不能借，「改一点点再用」也不行。

## 2. 提出 5 个方向

每个方向都要写清下面几项：

- **名字**：四到六个字。
- **取材来源**：写成「领域 + 具体来源」。来源必须是具体的、非网页的现实物件，比如某类印刷品、标牌、仪器面板、包装、某个年代的某种媒介。它要具体到能去找到实物照片，比如：
  - 「1970 年代日本国铁的硬纸车票」
  - 「苏联收音机的调谐刻度盘」
  - 「西药的折叠说明书」

  「复古」「赛博朋克」「极简」这类风格标签不算来源，别的网站或 App 也不算。
- **从来源里拿什么**：
  - 配色，附 3–5 个色值；
  - 字体，分标题、正文、标签，写出具体字体名；
  - 版式规律；
  - 材质和纹理；
  - 一个招牌物件或组件；
  - 一个动效。
- **为什么适合这个子站**：一两句，要和子站的内容挂钩。

硬性要求：

- **领域不重复。** 5 个方向的来源领域两两不同，比如不能两个都是票据，或两个都是地图。
- **避开禁区。** 不能和禁区清单里已用的领域重复。也不能和弃稿里的方向相同或相近：同一个具体来源算相近，同一个领域且长得像也算。
- **参考图或关键词的配额。** 如果站主给了参考图或关键词，至少 2 个方向从它出发，并写明是从哪一点出发的；至少 2 个方向完全不管它。
- **拉开差距。** 5 个方向至少要在以下两三个维度上彼此不同：明暗、色彩饱和度、字体性格（衬线、无衬线、手写、等宽、展示体）、信息密度。不要 5 个都是米色纸张。
- **避开全站禁令。**
  - 通用 AI 网页味：紫蓝渐变、毛玻璃、圆角加柔和阴影的卡片、Inter 或 Roboto、居中大标题配三张特性卡。
  - 素白方框当面板。

先把 5 个方向的文字发给站主，每个一小段，然后直接开始做样张。只有站主说要先看文字再做的时候才停下来等。

## 3. 每个方向做一屏样张

- **位置。** 放在 `设计世界/样张/<代号>/<两位序号>-<短名>.html`，例如 `设计世界/样张/xyz/01-guotie-chepiao.html`。一个方向一个独立的 HTML 文件，CSS 和 JS 都写在文件里。
- **不动正式代码。** 下面这些一律不碰：
  - `src/`、`game/`；
  - 各个页面入口、`vite.config.js`、`src/pages.js`；
  - 现有的 DESIGN.md。
- **内容。** 画子站首屏真实的样子，用真内容：子站名、真实的题目、规则、按钮文案。要画出这个方向的招牌物件。只做一屏，不滚动。
- **尺寸。** 页面在 1440×900 和 390×844 下都要成立。手机为主的子站以 390×844 为准，桌面版可以把手机画板居中，外面加一圈框。
- **字体。** 从 jsDelivr 加载，因为 Google Fonts 在这台电脑上不可靠。
  - 拉丁字体：`https://cdn.jsdelivr.net/fontsource/fonts/<字体slug>@latest/latin-<字重>-<normal|italic>.woff2`
  - 中文字体用按 unicode-range 分片的包，例如：
    - `https://cdn.jsdelivr.net/npm/lxgw-wenkai-webfont@1.7.0/style.css`（霞鹜文楷）
    - `https://cdn.jsdelivr.net/npm/@fontsource/<字体slug>@5/index.css`，例如 `zcool-kuaile`、`noto-serif-sc`
  - 只要某个字重时，用 `@5/<字重>.css`，比如 `noto-serif-sc@5/900.css`。
  - 标题不能用 Impact、Arial Black 或系统黑体。
- **质量。** 做之前先读 `.claude/skills/impeccable/reference/craft-floor.md`，遵守里面的检查项（对比度、字距、焦点、选区颜色等）和禁用清单。方向本身由取材来源决定，不由那份文件决定。
- **动效。** 截图只能看到静止的最终状态，所以动效写在方向说明里就行。可以在 HTML 里做出来，但截图前它必须已经停在最终状态。

## 4. 截图给站主

1. 截图，每个方向一条命令：

   ```
   .claude/skills/impeccable/scripts/impeccable shot 设计世界/样张/<代号>/<序号>-<短名>.html --viewport 1440x900,390x844 --out 设计世界/样张/<代号>/shots/<序号>-<短名>
   ```

   每个目录里会生成 `1440x900.png` 和 `390x844.png`。
2. 发出去之前，自己先用 Read 看一遍每张截图：
   - 字体真的加载了吗？对一下字形。没加载上的话，截图是骗人的。
   - 有没有溢出或截断？
   - 有没有一眼就是「AI 网页」的地方？

   有问题先改，再重新截图。
3. 拼一张总览图：

   ```
   python -I .claude/skills/new-world/scripts/contact_sheet.py 设计世界/样张/<代号>/shots 设计世界/样张/<代号>/总览.png
   ```

4. 用 SendUserFile 把总览图和每个方向的桌面截图、手机截图发给站主。每个方向配一句话：名字加取材来源。
5. 用 AskUserQuestion 问站主选哪个。选项是 5 个方向，站主还可以用「其他」回答：
   - **「选 X，但要改 Y」**：在那份样张上改一轮，重新截图，确认以后再进入第 5 步。
   - **「都不要」**：5 个方向全部记进弃稿，回到第 2 步，重新提 5 个新方向。

## 5. 站主选定之后

只有站主明确选定了一个方向，才做这一步。

1. **写 DESIGN.md。** 放在第 0 步定下的源码目录里，比如 `src/<代号>/DESIGN.md`。
   - 格式照 impeccable 的 `.claude/skills/impeccable/reference/document.md`：
     - YAML frontmatter：颜色、字体、圆角、间距和组件的 token，都从选定的样张里取真实值；
     - 八个固定英文标题的章节，标题不能改，正文写中文。
   - 文件第一行写：`<!-- SEED: 由 /new-world 选定的世界；正式代码写好后运行 /impeccable document 刷新 -->`
   - Overview 里写 Creative North Star，并单独写一行 `**取材来源：** <领域> · <具体来源>`。以后排除撞车就靠这一行。
   - Do's and Don'ts 里写两类内容：这个世界自己的规矩；不沿用小镇和其他子站的配色、字体、组件。
   - 写完用 `.claude/skills/impeccable/scripts/impeccable context --target <源码目录>/<任意文件名>` 检查一下，`designPath` 应该指向这份新文件。
2. **存定稿样张。** 把选中的 HTML 和它的两张截图复制到 `设计世界/定稿/<代号>/`。这个目录会进仓库，写正式代码时拿它当参照。
3. **记弃稿。** 把没选中的方向追加到 `设计世界/弃稿.md`，格式见那个文件开头的说明，截图路径也一起记上。如果站主说了不选的理由，也记上。
4. **告诉站主世界定好了。** 下一步按 `设计世界/开新子站.md` 第 3 步开始搭代码。不要自己开始写正式代码。

## 不做的事

- 不改正式代码。
- 站主选定之前不写 DESIGN.md。
- 选中的方向不记进弃稿，弃稿里的旧条目也不删。
- 不重新提弃稿里有过的方向。
